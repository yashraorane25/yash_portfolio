# Yash Umesh Raorane — Portfolio

A personal developer portfolio showcasing my engineering projects, experience, technical skills, and background in building distributed backends, intelligent systems, and scalable web applications.

---

## 🚀 Built With

- **Framework & Runtime:** [React 19](https://react.dev/), [TypeScript](https://www.typescriptlang.org/)
- **Build Tool:** [Vite 6](https://vitejs.dev/)
- **UI & Styling:** [Material UI (MUI v9)](https://mui.com/), [Emotion](https://emotion.sh/), [Tailwind CSS](https://tailwindcss.com/)
- **Animations:** [Motion](https://motion.dev/)
- **Icons:** [Lucide React](https://lucide.dev/)

---

## ✨ Features

- **Responsive & Modern Design:** Optimized for seamless viewing across mobile, tablet, and desktop screens.
- **Dark / Light Theme Toggle:** Interactive theme switching with custom MUI palettes and smooth transitions.
- **Featured Projects Showcase:** Highlighted projects with tech stack badges, deep-dive architectural summaries, and direct GitHub links.
- **Experience & Education Timelines:** Structured presentation of work history, education, and achievements.
- **Interactive Micro-Interactions:** Smooth scrolling, hover micro-animations, and viewport-triggered entrance effects.

## 🛠️ Getting Started

### Prerequisites

- **Node.js:** `^20.19.0` or `>=22.12.0` recommended
- **npm:** `v10+`

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/yashraorane25/yash_portfolio.git
   cd yash_portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 📦 Available Scripts

| Command | Description |
| :--- | :--- |
| `npm run dev` | Starts the Vite local development server on port `3000` |
| `npm run build` | Compiles TypeScript and creates an optimized production build in `dist` |
| `npm run preview` | Runs a local web server to preview the production build |
| `npm run lint` | Runs the TypeScript compiler (`tsc --noEmit`) to verify type integrity |
| `npm run clean` | Deletes the `dist` build directory |
